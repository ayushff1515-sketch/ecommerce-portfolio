
# ShopVerse - Professional E-Commerce Portfolio

## Overview
A sophisticated e-commerce web application demonstrating full-stack development capabilities with modern JavaScript technologies. This project showcases expertise in building production-ready applications with seamless user experiences.

## Technical Highlights
- React 18 with Hooks and Context API for state management
- Vite for lightning-fast development and optimized builds
- Supabase for secure authentication with Google OAuth
- REST API integration with DummyJSON for product data
- Responsive design across all screen sizes
- Performance optimization with lazy loading and memoization

## Core Features
🔐 **Authentication**: Secure Google OAuth integration
🛒 **Shopping Cart**: Complete cart management with persistence
💳 **Payment Flow**: Demo checkout experience
🔍 **Product Search**: Real-time search with debouncing
📊 **Filtering**: Category and price range filters

## Business Logic
- Dynamic product pricing with tax calculation
- Shipping cost calculation based on order total
- Stock availability indicators
- Rating system with star reviews

## Development Practices
- Component-based architecture
- Custom hooks for reusable logic
- Environment variable management
- Git version control
- Production build optimization

## Deployment
Successfully deployed using Netlify/Vercel with continuous deployment from GitHub.
