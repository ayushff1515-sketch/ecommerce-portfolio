# ShopVerse - Complete E-Commerce Platform

## 📖 About

**ShopVerse** is a comprehensive e-commerce web application designed to showcase modern web development practices. It combines a sleek, responsive user interface with robust functionality including product browsing, shopping cart management, user authentication, and payment processing.

Built with React and Vite, this project demonstrates my ability to create production-ready web applications using current industry standards and best practices.

## 🎯 Key Features

### 🛒 Shopping Experience
- Browse products with dynamic listing
- Search products in real-time
- Filter by category and price range
- Sort by rating and price
- Add items to cart with quantity control
- Persistent cart state across sessions

### 🔐 User Management
- Google OAuth authentication via Supabase
- Secure session handling
- User profile display
- Protected routes for authenticated users

### 💳 Checkout Process
- Order summary with itemized list
- Shipping and tax calculation
- Multiple payment method options (Card, PayPal, Apple Pay, Google Pay)
- Payment processing simulation
- Success confirmation page

### 🎨 User Interface
- Modern, clean design with gradient accents
- Fully responsive across all screen sizes
- Interactive hover effects and animations
- Loading states and error handling
- Professional typography and spacing

## 🚀 Performance Optimizations

- ✅ Lazy loading for components
- ✅ Debounced search input
- ✅ Memoized components
- ✅ Optimized production builds
- ✅ Image optimization

## 🔧 Installation & Setup

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation Steps

```bash
# 1. Clone the repository
git clone https://github.com/yourusername/ecommerce-portfolio.git

# 2. Navigate to project folder
cd ecommerce-portfolio

# 3. Install dependencies
npm install

# 4. Create environment file
cp .env.example .env

# 5. Add your environment variables
# VITE_SUPABASE_URL=your_supabase_url
# VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
# VITE_STRIPE_PUBLISHABLE_KEY=your_stripe_key

# 6. Start development server
npm run dev

# 7. Build for production
npm run build

# 8. Preview production build
npm run preview
